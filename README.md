# 🛒 E-Commerce Web Application

A responsive e-commerce web application built with React.js, featuring dynamic product listings, cart and order management, and persistent state handling.

## 🚀 Features
- Dynamic product listing using REST APIs
- Add to cart, remove from cart, and order management
- CRUD operations for cart and orders
- Global state management using Context API
- localStorage persistence for cart data
- Responsive UI with Tailwind CSS
- Client-side routing with React Router
- Toast notifications for user actions

## 🛠 Tech Stack
- React.js
- Context API
- React Router
- Tailwind CSS
- RESTful APIs
- localStorage
- React Hot Toast

## 📌 What I Learned
- Managing global state using Context API
- Building reusable React components
- Integrating REST APIs into frontend applications
- Persisting application state using localStorage
- Designing scalable and responsive UI
